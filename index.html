About the project:

It also features an AI-powered tool that generates custom recipes based on ingredients provided by the user.

Key Features:

  • 🔹 User registration and secure login.
  • 🔹 Create, edit, and delete personal recipes.
  • 🔹 View and explore public recipes shared by other users.
  • 🔹 AI-powered recipe generation with Spoonacular API.
  • 🔹 Secure authentication system using JWT.
  • 🔹 Responsive and intuitive user interface.

🛠 Technologies Used:

  • Frontend: Angular, TypeScript, Bootstrap.
  • Backend: Django Rest Framework (DRF), Python.
  • Authentication: JSON Web Token (JWT).
  • Database: MySQL.
  • API: REST API.
  • AI Integration: Spoonacular API for automatic recipe generation.
