Ricco Burgers – Project Details

Overview: E-commerce app for a fast-food chain. Users can browse the menu, create, edit, and delete their profiles, place online orders, and complete secure payments through MercadoPago integration. The platform includes role-based authentication (users/admins), real-time order tracking, and a management dashboard where administrators can update products, control inventory in real time, and edit site content.

Main Features: Shopping cart, MercadoPago payments, real-time order tracking,role-based access control, user authentication, admin dashboard (CRUD).

Stack: Angular 17, TypeScript, JavaScript, HTML, CSS, Bootstrap, Python, Django REST Framework, MySQL, JWT (Authentication), MercadoPago API.

RicettarioX – Project Details

Overview: Recipe management with AI-powered generation. Users can create, edit, and manage their own recipes. An integrated AI module (via Spoonacular API) also suggests custom recipes based on available ingredients.

Main Features: AI-based recipe generator, secure auth (JWT), public/private recipe visibility, and responsive UI.

Stack: Angular, DRF, MySQL, Spoonacular API.

RiccoApp – Project Details

Overview: RiccoApp is a native Android application developed for Ricco Burgers. It allows users to browse the menu, create, edit, and delete their profiles, place online orders, and complete secure payments directly from their mobile devices.Like the web platform, administrators can access a management panel to update products, control inventory, and edit app content.The mobile app is designed to work either independently or integrated with the Ricco Burgers web platform.

Main Features: Auth system, profile management, dynamic sections.

Stack: Java, Django REST Framework, JWT, Retrofit, MySQL, Android Studio.

QuizWordApp – Project Details

Overview: QuizWordApp is an interactive quiz application developed with React Native. It allows users to answer multiple-choice questions, calculates scores based on difficulty, and displays a detailed summary at the end of the quiz.

Main Features:

  • Dynamic question loading from the Open Trivia Database API.
  • Navigation between screens using React Navigation.
  • Score calculation adjusted to each question's difficulty.
  • Per-question timer to increase challenge.
  • Modern UI with gradient backgrounds using expo-linear-gradient.
  • Option to share results with friends.

Stack: React Native (0.73.6), Axios, React Navigation, Expo, expo-linear-gradient, react-native-safe-area-context, he, react-native-reanimated.
